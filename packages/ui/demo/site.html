Get started

Point your container runtime at the mirror once; pulls from Docker Hub then go through it without changing a single image name.

  1. Add the mirror to the Docker daemon

    In /etc/docker/daemon.json; merge it into what is already there.

    /etc/docker/daemon.json
    {
  "registry-mirrors": ["https://docker.linkos.io"]
}

  2. Restart Docker

    Running containers restart with it, unless live-restore is on.

    sudo systemctl restart docker

  3. Pull as usual

    Images from other registries need the mirror's address in their name; convert one.

    docker pull nginx:1.27

Convert an image

Paste an image from any of the registries below to get the name to pull through the mirror.

docker pull ghcr.linkos.io/containerd/busybox:1.36
Try nginx:1.27 quay.io/coreos/etcd:v3.5.0 registry.k8s.io/pause:3.10

Questions

A pull fails with 404 or "manifest unknown"

Check the image name. Docker Hub's official images need library/ before their name, as in library/nginx.

Are images cached?

No. Every pull goes to the registry; the mirror stores nothing.

Can I push or search?

No. The mirror only pulls.
