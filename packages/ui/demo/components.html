Rollback, done

The deploy script now keeps the previous release and restores it when a health check fails. See scripts/deploy.sh and the runbook; the change is safe to merge.

  1. Back up the current release to app.bak.
  2. Deploy, then check health:
    • three tries, five seconds apart;
    • on failure, move app.bak back.
  3. Remove the backup after a day.

Only the latest release is kept, so a second failed deploy cannot roll back twice.
